# Release status / 发布状态

**Experimental 0.0.1 — complete production acceptance is not claimed.**

The package version is owned by [pubspec.yaml](pubspec.yaml), with one generated Gallery projection. This repository provides the Flutter library, Gallery, tests, component contracts, consumer Skill and source-specific notices. It is available as a public Git repository; it is not advertised as a pub.dev release.

版本由 [pubspec.yaml](pubspec.yaml) 唯一拥有，Gallery 使用生成投影。本公开仓库提供 Flutter 库、Gallery、测试、组件契约、消费 Skill 及来源声明，尚未声明发布至 pub.dev。

Read [verification and limitations](docs/ACCEPTANCE.md) for accepted exceptions, failing measurements and missing platform evidence. That page owns the public limitation summary. Raw acceptance material and operational records are retained separately; historical passes do not validate changed source.

已接受例外、失败测量和平台证据缺口统一见[验证与限制](docs/ACCEPTANCE.md)。原始验收材料和操作记录独立保存，旧源码的通过结果不替新源码背书。

Scope and checks are defined in [library.json](library.json), appearance in [DESIGN](docs/DESIGN.md), public contracts in [API](docs/API.md), and redistribution boundaries in [RIGHTS](docs/RIGHTS.md). Changes are recorded in [CHANGELOG](CHANGELOG.md).
