# animal-island-ui 动森海岛设计风格 (Flutter)

animal_island_ui 是基于动森治愈美学的 Flutter 企业生产级开源组件库 — 36 个标准组件、101 款可爱矢量图标、零三方 UI 依赖。

## 场景速查

| 场景 | 入口 |
| :--- | :--- |
| Flutter 项目 — 在 pubspec.yaml 中引入 animal_island_ui | [references/flutter-project.md](references/flutter-project.md) |
| 单文件快速原型与独立 Widget 开发 | [references/standalone-dart.md](references/standalone-dart.md) |

## 风格核心概述

温暖羊皮纸背景 (#F8F8F0)、大地棕文本 (#794F27，绝不使用纯黑)、薄荷水绿品牌色 (#19C8B9)、50px 大胶囊圆角、Primary 按钮专有纯切面 3D 阴影、Nunito 与 Noto Sans SC 圆润字体、贝塞尔曲线有机水滴模态框 (`AnimalBlobClipper`) 与燕尾飘带标题 (`AnimalTitle`)。
