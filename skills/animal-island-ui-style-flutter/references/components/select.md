## Localization
When placeholder is null, the select uses the generated localized default. Option labels remain caller-owned. The clear action uses generated AnimalLocalizations; an explicit placeholder overrides only the default prompt.

## Interaction and accessibility

The trigger, menu options and clear action each respond to pointer taps and to Enter or Space when focused, and activate once per gesture. Keyboard navigation inside the popup menu is handled by the select itself.
