# Animal Island UI documentation

Guides and references for building island-style Flutter interfaces with
`animal_island_ui`. [中文](../zh/README.md)

## Getting started

- [Project README](../../README.md): installation, quick start and component overview.
- [Live Gallery](https://ibuprofenighty.github.io/animal-island-ui-flutter/): every
  component, the icon browser and three example workflows.
- Import everything from `package:animal_island_ui/animal_island_ui.dart`.
